# Social Fabric — Gallery

Drop your model / lookbook images here **or** in `Assets/Gallery/`. Supported formats: **JPG, JPEG, PNG, WebP, GIF**.

The Models page auto-syncs from this folder when you run the dev server or build.

## Tips

- Use descriptive filenames (e.g. `subway-look-01.jpg`) — they become captions on the site.
- Any order works; the first image gets a larger hero tile in the grid.
- Keep filenames simple (letters, numbers, hyphens) for best results.

After adding images, restart `npm run dev` or run:

```bash
npm run sync:gallery
```
